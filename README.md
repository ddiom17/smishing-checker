# 🛡️ Smishing Checker — проверка SMS на мошенничество

Гибридный детектор мошеннических SMS для Кореи и Казахстана:
ИИ-модель (TF-IDF + Logistic Regression) + анализ по правилам.
Интерфейс: 한국어 / English.

## Файлы
| Файл | Что это |
|---|---|
| `app.py` | сайт (Streamlit) |
| `train.py` | обучение модели, печатает точность по каждому языку |
| `spam.csv` | английский датасет с Kaggle (SMS Spam Collection), скачивается отдельно |
| `korean_sms.csv`, `kz_sms.csv` | корейские и казахстанские сообщения (`label,text`) |
| `extra_*.csv` | любые дополнительные наборы данных (`label,text`), подхватываются автоматически |
| `feedback.csv` | появляется сам: ответы пользователей «맞아요 / 틀렸어요» |
| `.streamlit/config.toml` | цвета и тема сайта |

## Запуск у себя
```
pip3 install -r requirements.txt
python3 train.py
python3 -m streamlit run app.py
```

## Как повысить точность
1. Добавлять реальные сообщения в `korean_sms.csv` / `kz_sms.csv` (цель: 300+ на язык, примерно поровну spam и ham).
2. Запускать `python3 train.py` и смотреть таблицу: строки с пометкой «меньше 80%» показывают языки, где нужно больше данных.
3. Периодически переносить строки из `feedback.csv` (после проверки!) в основные файлы и переобучать.

## Публикация в интернете
1. Создать репозиторий на github.com и загрузить туда все файлы (вместе с `spam.csv` и папкой `.streamlit`; `model.joblib` загружать не нужно).
2. Зайти на share.streamlit.io → войти через GitHub → **Create app** → выбрать репозиторий, файл `app.py` → **Deploy**.
3. При первом запуске сайт сам обучит модель (около минуты) и получит ссылку вида `https://....streamlit.app`.
